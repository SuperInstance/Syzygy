# 0006 — 16-point radix-2 fixed-point FFT

- **WHAT** — A 1-D, 16-point, radix-2 decimation-in-time FFT in 14-bit fixed
  point (`>>14`, trig from a static table), for a temporal/acoustic sample window
  (hydrophone audio, per-row luminance). Zero allocation, no FPU.
- **STATE** — **DRAWN**. The seed has a complete, transcribable kernel.
- **RUNS** — nothing yet. Target surface: `include/syz_fft.h` with
  `syz_fft16(int32_t re[16], int32_t im[16])` in place, plus the single
  16-entry sine-phased trig table (SCARF-2).
- **SHORTCUT (planned)** — fixed N=16, and the honest version keeps the explicit
  **bit-reversal permutation pass** (SCARF-1, timber B). It works and is testable
  (an impulse → flat spectrum; a single sinusoid → one bin).
- **ASSUMES** — 0002 (arena) only if buffers are staged; the in-place form needs
  no allocation. Fed by 0004 (a luma/audio window). Consumed inside 0005.
- **BETTER-WHEN (SCARF-1)** — the **bit-reversal-free** form the READMEs promise
  (blob:78, 806) requires a static shuffle mask / fully-unrolled 16-point DFT
  (blob:8028-8029). That is the upgrade; until it exists, "bit-reversal-free" is
  aspirational and the mark says so.
- **CAUTION (SCARF-2)** — the seed ships **two** trig tables in different phases
  (`CU_SIN_TABLE` sine-phased blob:3240; `ULTIMATE_TRIG_TABLE` cosine-phased
  blob:8305). Use **one** sine-phased table and derive cosine with the `+4`
  index offset the kernel already uses (blob:3275). See `ARCHITECTURE.md`.
- **SEED** — `docs/seed/blob.md` 3236-3292 (`chiaroscuro_fft_fixed`, the
  butterfly + bit-reversal), 7322-7332 (the fixed-point butterfly math),
  8305-8308 (the second trig table — the duplicate to reconcile).
- **NEXT** — 0005 (fuse the window transform into the pass), then the unrolled
  bit-reversal-free form to close SCARF-1.
