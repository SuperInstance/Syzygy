# 0006 — 16-point radix-2 fixed-point FFT

- **WHAT** — A 1-D, 16-point, radix-2 decimation-in-time complex FFT in Q14
  fixed point (`>>14`, one static sine-phased trig table). In-place, zero
  allocation, libc-free, FPU-free, header-only: `include/syz_fft.h`.
- **STATE** — **HEWN** (was DRAWN). `syz_fft16(int32_t re[16], int32_t im[16])`
  exists and `tests/test_fft.c` passes via `sh tests/run.sh`.
- **RUNS** — `sh tests/run.sh` -> test_fft: 15 checks, 0 failures (plus 31 for
  0001/0003). Checks: table symmetry; impulse -> flat (1000 +-2, imag +-2);
  shifted impulse -> |X_k| flat +-2; DC 100 -> bin0 = 1600 +-2, others <= 2;
  cos tones in bins 1/3/5 -> X[b], X[16-b] = 8000 +-24, other bins <= 16;
  linearity F(a+b)=F(a)+F(b) within 4 LSB and F(2x)=2F(x) within 4; and 200
  random full-scale (|x|<=4095) complex vectors vs a double-precision DFT:
  **tolerance abs error <= 8 LSB, measured worst 2 LSB**. Output is unscaled
  (gain N=16).
- **SHORTCUT** — Fixed N=16. Explicit bit-reversal pass kept (SCARF-1 timber
  B). No per-stage scaling, so inputs must satisfy |re|,|im| <= 4095 to keep
  int32 products from overflowing in the last stage. Rounds (+2^13) instead of
  the seed's bare truncating `>>14`. Arithmetic right-shift of negatives assumed.
- **SCARF-1 resolved** — per ARCHITECTURE.md: the real-now FFT *has* the
  bit-reversal pass; "bit-reversal-free" is not claimed. Aspirational until the
  unrolled/static-shuffle form exists.
- **SCARF-2 resolved** — per ARCHITECTURE.md: one sine-phased table
  (`SYZ_SIN_TABLE`, timber A); cosine = `T[(i+4)&15]`. `ULTIMATE_TRIG_TABLE`
  (cos-phased, blob:8305) is unused. A test asserts the table symmetry.
- **SEED BUG FOUND (not a scarf in ARCHITECTURE.md)** — the seed kernel
  (blob:3275-3276) names its variables swapped (`sinW` reads the +4 = cosine
  entry) and so rotates by e^{+j}, i.e. not the forward DFT its own math
  (blob:7322-7332, W_N^nk = cos - j sin) defines. Here c=cos, s=sin and
  t = (re*c + im*s) + j(im*c - re*s). Verified against a double DFT oracle.
  Worth a line in ARCHITECTURE.md as SCARF-7-like if others hit it.
- **ASSUMES** — Fed by 0004 (a luma/audio window, im[] zeroed). 0002 (arena)
  only if buffers are staged; the in-place form needs none. Consumed inside 0005.
- **BETTER-WHEN** — The bit-reversal-free static-shuffle / fully unrolled
  16-point DFT exists (blob:8028-8029; closes SCARF-1); and a per-stage `>>1`
  scaled variant lifts the 12-bit input bound. Honest idea: for real luminance
  input, a real-FFT (two rows packed as re/im) halves the work.
- **SEED** — `docs/seed/blob.md` 3236-3292 (`chiaroscuro_fft_fixed`), 7322-7332
  (butterfly math), 8305-8308 (duplicate trig table, deliberately unused).
- **NEXT** — 0005 (fuse the window transform into the register pass; it can
  now call `syz_fft16` on a luma row as a HEWN dependency), then the unrolled
  bit-reversal-free form to close SCARF-1.
